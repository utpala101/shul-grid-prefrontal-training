# 舒尔特方格 Schulte Grid

前额叶锻炼工具 — 在方格中按顺序依次点击 1→N，训练注意力与反应速度。

## 功能

- **多种尺寸**: 3×3 ~ 10×10
- **计时与记录**: 自动计时，本地存储历史成绩
- **成绩分布图**: 核密度估计曲线，直观展示成绩分布
- **错误提醒**: 连续点错 3 次非阻塞浮窗提醒
- **响应式**: 桌面与移动端适配

## 使用

1. 选择方格尺寸
2. 点击「开始训练」
3. 视线固定中心，用余光搜索并按顺序点击 1, 2, 3…
